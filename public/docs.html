HTTP API · VERSION 1

Integrasikan PDF2AI.

Upload PDF, pantau proses OCR, lalu ikuti URL pada response untuk mengambil PDF, Markdown, dan hasil Tanya AI.

BASE URL AKTIF {{BASE_URL}}
Perlu login TOTP.

Halaman dokumentasi ini hanya dapat dibuka setelah login. Client eksternal memakai API key untuk mengakses endpoint terproteksi di bawah prefix /v1/*.

01

QUICK START

Dari PDF ke Markdown

Alur asynchronous direkomendasikan untuk OCR dan dokumen besar.

  1. 1
    Buat API keyDari dashboard setelah login TOTP.
  2. 2
    Upload PDFSimpan ID job dari response.
  3. 3
    Periksa statusTunggu sampai completed.
  4. 4
    Ikuti URL hasilAmbil PDF, Markdown, atau hasil AI.
Shell · Alur lengkap 
export PDF2AI_API_KEY="p2ai_..."

# 1. Upload PDF dan salin job.id dari response
curl -F "file=@document.pdf;type=application/pdf" \
  -H "X-API-Key: $PDF2AI_API_KEY" \
  {{BASE_URL}}/v1/jobs

# 2. Periksa status job
curl -H "X-API-Key: $PDF2AI_API_KEY" \
  {{BASE_URL}}/v1/jobs/JOB_ID

# 3. Ambil Markdown setelah status completed
curl -H "X-API-Key: $PDF2AI_API_KEY" \
  {{BASE_URL}}/v1/jobs/JOB_ID/markdown

# 4. Periksa model yang dapat digunakan
curl -H "X-API-Key: $PDF2AI_API_KEY" \
  {{BASE_URL}}/v1/ai/models

# 5. Ambil daftar hasil AI (boleh masih kosong)
curl -H "X-API-Key: $PDF2AI_API_KEY" \
  {{BASE_URL}}/v1/jobs/JOB_ID/ai
02

AUTENTIKASI

Gunakan X-API-Key

Login ke dashboard dengan TOTP, klik API Key, lalu pilih Buat API key. Key lengkap hanya ditampilkan sekali. Membuat key baru langsung menonaktifkan key lama.

REQUEST HEADER X-API-Key: p2ai_...
Jangan taruh API key di frontend publik.

Simpan sebagai secret atau environment variable pada backend Anda. Endpoint /v1/health adalah satu-satunya endpoint API yang tidak memerlukan key.

GET /v1/health PUBLIK

Memeriksa kesiapan API, backend OCR, dan statistik antrean.

cURL 
curl {{BASE_URL}}/v1/health
Contoh response · 200 OK 
{
  "status": "ok",
  "mode": "hybrid",
  "hybridReady": true,
  "queue": {
    "queued": 0,
    "processing": 1,
    "completed": 8,
    "failed": 0
  }
}
GET /v1/ai/models API KEY

Mengambil daftar model AI yang sudah diimpor dan disimpan melalui dashboard. Endpoint ini tidak menghubungi provider ulang dan tidak mengembalikan Base URL maupun token provider.

cURL 
curl -H "X-API-Key: $PDF2AI_API_KEY" \
  {{BASE_URL}}/v1/ai/models
Contoh response · 200 OK 
{
  "configured": true,
  "modelsUrl": "/v1/ai/models",
  "models": ["model-cepat", "model-teliti"],
  "defaultModel": "model-teliti",
  "updatedAt": "2026-08-01T09:00:00.000Z"
}

Jika AI belum dikonfigurasi, response tetap 200 OK dengan configured: false, daftar kosong, dan defaultModel: null.

GET /v1/jobs/:id API KEY

Mengambil metadata dan status job. Poll endpoint ini sampai status menjadi completed atau failed. Gunakan URL pada object job agar client tidak perlu menyusun endpoint turunannya.

cURL 
curl -H "X-API-Key: $PDF2AI_API_KEY" \
  {{BASE_URL}}/v1/jobs/JOB_ID
queuedMenunggu worker.
processingSedang diekstrak.
completedHasil tersedia.
failedLihat field error.
Contoh response completed · 200 OK 
{
  "job": {
    "id": "JOB_ID",
    "originalName": "document.pdf",
    "status": "completed",
    "jobUrl": "/v1/jobs/JOB_ID",
    "pdfUrl": "/v1/jobs/JOB_ID/pdf",
    "markdownUrl": "/v1/jobs/JOB_ID/markdown",
    "aiModelsUrl": "/v1/ai/models",
    "aiResultsUrl": "/v1/jobs/JOB_ID/ai"
  }
}

aiModelsUrl menunjuk ke daftar model global yang dapat digunakan untuk Tanya AI. aiResultsUrl selalu tersedia dan mengarah ke koleksi hasil AI milik job. Koleksi dapat kosong jika Tanya AI belum pernah dijalankan.

GET/v1/jobs/:id/markdown

Mengambil PDF sumber atau Markdown hasil ekstraksi. Tambahkan ?download=1 agar response dikirim sebagai attachment.

MARKDOWN RESPONSEtext/markdown; charset=utf-8
POST /v1/jobs/:jobId/ai API KEY

Mengirim Markdown dari job selesai ke provider AI yang sudah dikonfigurasi. Model harus berasal dari daftar model yang diimpor melalui dashboard. Request menunggu jawaban provider, lalu hasilnya disimpan secara persisten.

FieldTipeWajibKeterangan
modelstringYaModel yang sudah diimpor.
messagestringYaInstruksi atau pertanyaan untuk AI.
templateIdstring | nullTidakID template yang dipakai dari dashboard.
cURL 
curl -X POST {{BASE_URL}}/v1/jobs/JOB_ID/ai \
  -H "X-API-Key: $PDF2AI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "MODEL_ID",
    "message": "Ringkas dokumen dan tuliskan poin tindakan."
  }'
Bentuk response · 201 Created 
{
  "result": {
    "id": "HASIL_AI_ID",
    "jobId": "JOB_ID",
    "model": "MODEL_ID",
    "prompt": "Ringkas dokumen dan tuliskan poin tindakan.",
    "content": "Jawaban dari AI...",
    "createdAt": "2026-08-01T09:00:00.000Z",
    "jobUrl": "/v1/jobs/JOB_ID",
    "aiModelsUrl": "/v1/ai/models",
    "aiResultsUrl": "/v1/jobs/JOB_ID/ai",
    "resultUrl": "/v1/jobs/JOB_ID/ai/HASIL_AI_ID"
  }
}

Header Location dan field resultUrl menunjuk ke hasil AI yang baru dibuat.

GET /v1/jobs/:jobId/ai API KEY

Mengambil seluruh hasil Tanya AI milik sebuah job, urutan terbaru. URL endpoint ini tersedia sebagai job.aiResultsUrl pada response job.

cURL 
curl -H "X-API-Key: $PDF2AI_API_KEY" \
  "{{BASE_URL}}/v1/jobs/JOB_ID/ai"
Bentuk response · 200 OK 
{
  "jobUrl": "/v1/jobs/JOB_ID",
  "aiResultsUrl": "/v1/jobs/JOB_ID/ai",
  "results": [
    {
      "id": "HASIL_AI_ID",
      "jobId": "JOB_ID",
      "content": "Jawaban dari AI...",
      "jobUrl": "/v1/jobs/JOB_ID",
      "aiModelsUrl": "/v1/ai/models",
      "aiResultsUrl": "/v1/jobs/JOB_ID/ai",
      "resultUrl": "/v1/jobs/JOB_ID/ai/HASIL_AI_ID"
    }
  ]
}
GET /v1/jobs/:jobId/ai/:aiId API KEY

Mengambil satu hasil AI. Gunakan resultUrl dari response pembuatan atau daftar hasil agar kombinasi jobId dan aiId selalu benar.

cURL 
curl -H "X-API-Key: $PDF2AI_API_KEY" \
  {{BASE_URL}}/v1/jobs/JOB_ID/ai/HASIL_AI_ID

Response berbentuk { "result": { ... } }. Jika hasil bukan milik job tersebut, server mengembalikan 404 Not Found.

DELETE /v1/jobs/:id API KEY

Menghapus PDF, metadata, Markdown, dan seluruh hasil AI secara permanen. Hanya job berstatus completed atau failed yang dapat dihapus.

cURL 
curl -X DELETE \
  -H "X-API-Key: $PDF2AI_API_KEY" \
  {{BASE_URL}}/v1/jobs/JOB_ID

204 No Content jika penghapusan berhasil.

05

ERROR HANDLING

Status HTTP

400Bad Request — field multipart salah atau request tidak valid.
401Unauthorized — API key hilang, salah, dicabut, atau sudah dirotasi.
404Not Found — ID job tidak ditemukan.
409Conflict — hasil belum siap atau status job tidak mengizinkan aksi.
413Payload Too Large — PDF melebihi batas ukuran.
415Unsupported Media Type — request bukan multipart/form-data.
500Internal Server Error — ekstraksi atau proses internal gagal.
502Bad Gateway — provider AI menolak request atau memberi response tidak valid.
503Service Unavailable — health check mendeteksi backend OCR belum siap.
504Gateway Timeout — provider AI tidak merespons sebelum timeout.
Bentuk error JSON
{
  "error": "API key tidak valid atau tidak dikirim."
}
